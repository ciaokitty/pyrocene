# Lia and the plant guide

Lia is a fictional field ecologist. Her portrait was created with the imagegen
skill and built-in image generation. The user requested an older Jane
Goodall-inspired character with the green scanline radio treatment in
`/tmp/meilei.png`. She is not represented as Jane Goodall herself. The dialogue
is original game writing, not quotations or an endorsement.

Current exploration asset: `lia-v1.png`, the original illustrated fictional
ecologist. The user requested its return after the Ash experiments. CSS applies
a green monochrome filter and retains the scanline overlay; the source bitmap
is unchanged. The restored expedition also uses v1. `lia-v2.png` is retained
as an unused alternative.
The portrait is deliberately small. There is no live character model or live
language-model call. The generation notes below describe v2, not the restored v1.

readable at 80px height. Very dark near-black green background. No text, no
logos, no other character, no border, no UI buttons, no scenery. Keep the
expression calm and intelligent, not smiling for a fashion photograph.

## Plant guide

Use real taxon-matched reference photographs. `plant-images.json` records each
file's author, license, original page, download URL and checksum. Cards show a
cropped frame without modifying the stored image; Sources states this and
links the applicable license. No generated vegetation is presented as a
botanical reference. Small list icons indicate growth form only.
