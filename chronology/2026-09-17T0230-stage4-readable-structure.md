# Readable structure in the restored map

The user accepted the selected-square rise/sink transition but could not read
plant shapes. The previous five-metre crops were stretched roughly 27 times in
the horizontal axes while retaining native heights. That distorted structure.

The restored expedition remains the default. We removed that stretch, retained
proportionate lower-stratum returns, and downloaded three individual tree
references from the same ForestScan Paracou archive. Their woody returns are
brighter than foliage. No procedural cones or invented raw scans were added.
These references have unknown botanical identity; game species labels are not
claimed as scan-derived identifications. Clicking a species shows its separately
identified photograph through a green terminal treatment.

Visual iteration rejected sparse small-tree references after inspecting the
first browser screenshot. Fuller scans replaced them. Original measured airborne
coordinates stay unchanged. The surrounding cloud remains visible, as requested.
The old photos, raw sources and experimental routes are retained.

Verification: `python3 -m unittest stage4.test_inline -v` exercises transitions,
clickable names, notes, reduced motion, another plot, failed-fetch retry, bounds,
mobile and the interactive Canvas fallback. Screenshots are in the external
`stage4/qa-expedition` artifact directory. User hardware still needs validation.

This Git checkpoint also captures the previously uncommitted Stage 4 history
and launcher integrations. The next work is communities, audio and camera-trap
references, using the same scene and explicit evidence boundaries.
