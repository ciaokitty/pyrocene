# Stage 4 returns to Stage 3

The user rejected the complexity of the expedition and asked for the known
Stage 3 loop with the point-cloud presentation. Island of Ash is the new
default. The earlier work remains at its own routes.

The original terminal game was played, then the new browser game was played
through wins and losses. It uses the original Python engine with a declared
teaching configuration. One action advances one night. Airborne LiDAR misses
young invasion; a close scan opens a broad measured-point composition without
a field-team confirmation. Remove and restore are the other interventions.

The biggest balance correction came from an initially misleading victory:
fire helped raise native cover while wildlife nearly collapsed. A longer
seedling window and four-night recovery hold now reward the tested early
responses. Spread and fire remain active. The event build includes the engine
and runs without internet or Blender/Unreal.

See `stage4/ASH_PLAYTEST.md` and `stage4/ASH_BALANCE.md` for reproducible checks
and limitations. No human group has yet established the fun or learning value
of this new baseline. Earlier chronology entries are preserved as history.
