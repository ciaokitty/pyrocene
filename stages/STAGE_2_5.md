Connectivity
---

There is a more important lesson than just lantana squares = higher ignition. Connectivity. A connected band of dry lantana is ignition prone, and capable of carrying, even strenghtening the fire bewtween fragments. 

So something like
```
isolated lantana
      []

              []

   []
```
is less dangerous than a line leading to a native patch or village 
```
spark -> [[[[[[]]]]]] -> village
```
This captures the continuous surfaces fuel fires. 
Removal reduces fuel load. 
Smart and strategic removal disconnects the fuel network.
However the most important lesson is this
1. At the start of the game there will be small sporadic fires, and identifying the lantana at this stage is prudent. This is like searching for seedlings.
2. At the point where the fuel network connects, the user is locked into a fire resilience strategy. This is like going after mature patches - more expensive, but we have no choice. 

So basically, stage 2 should lead to a connectivity network of lantana spread and to a bigger wildfire. We should make it so this actually happens, so we can make a pedogogy tool. There are a few ways to do this
1. Increase number of lantana players
2. Increase size of lantana patches 
3. Connect patches quicker 
4. Start with smaller random fires in the field so focus goes on player hunt 
5. The last fire should be one that's connected across patches and leads to either a natvie forest or village
